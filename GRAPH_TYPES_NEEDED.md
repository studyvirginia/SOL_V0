# Graph & Diagram Types Needed
*Compiled from full scan of all Math (19 files) and Science (25 files) curriculum JSON files.*

**Engine Key:**
- 🟢 **Desmos 2D** — interactive function/expression graphing
- 🔵 **Desmos Geometry** — compass-and-ruler constructions, labeled diagrams
- 🟡 **GeoGebra** — hybrid algebra+geometry (both modes)
- 🟠 **Matplotlib** — static raster PNG; best for data charts, custom scientific diagrams
- 🔴 **Gap** — none of the 4 engines handles this well; needs custom SVG or pre-made image

## Summary: Engine Strengths

| Engine | Best For |
|--------|----------|
| **Desmos 2D** | Any y = f(x) plot, inequalities, systems, trig functions, conics, parametric, polar, scatter + regression, number lines, statistical distributions |
| **Desmos Geometry** | Compass constructions, labeled triangles/circles, trig diagrams, transformations, vectors, ray diagrams, geometric proofs |
| **GeoGebra** | Backup/alternative for both Desmos modes; algebra + geometry hybrid; matrices/sliders |
| **Matplotlib** | All statistical charts (bar, pie, box, histogram, scatter, normal curve), scientific data plots, 3D solids, network/graph theory diagrams, labeled diagrams with custom annotations |

## Gaps — Needs Custom SVG or Pre-made Image

These diagram types **cannot be adequately generated** by any of the 4 engines:

| Category | Specific Types |
|----------|---------------|
| **Biology** | Cell organelle diagrams, DNA/RNA helix, VSEPR 3D molecular geometry, chromosome karyotypes, mitosis/meiosis stages, body system anatomy, homeostasis feedback loops, biogeochemical cycle diagrams, ecosystem succession |
| **Chemistry** | Bohr atom / electron shell model, Lewis dot structures, VSEPR molecular geometry |
| **Earth Science** | Geologic cross-sections, rock cycle diagrams, plate tectonic maps, water table cross-sections, thermohaline conveyor belt, weather maps, sun path diagrams, moon phases, eclipse geometry, star charts |
| **Physics** | Circuit diagrams (schematic), fluid flow through pipes, some wave/field visualizations |
| **Computer Science** | Flowcharts, complex algorithm diagrams |

**Recommendation for gaps:** Pre-render these as SVG/PNG assets at curriculum-authoring time, or use a specialized diagramming library (e.g., D3.js, Mermaid for flowcharts).
