Recommended replacement · Server-side Python

Recommended Geometry + 3D

Matplotlib handles all geometry TikZ does, plus functions and 3D, with near-100% reliability. AI generates clean Python code. Server executes in subprocess, returns PNG. No external tool install required beyond pip install matplotlib.

Sample AI Output (geometry)
import matplotlib.pyplot as plt
import matplotlib.patches as patches
import numpy as np

fig, ax = plt.subplots(figsize=(5, 5))
A, B, C = (0,0), (4,0), (0,3)
poly = plt.Polygon([A,B,C],
    facecolor='#dbeafe', edgecolor='#1d4ed8', lw=2.5)
ax.add_patch(poly)
for pt, lbl, off in [
    (A,'A',(-0.35,-0.3)),
    (B,'B',(0.1,-0.3)),
    (C,'C',(-0.35,0.1))]:
  ax.text(pt[0]+off[0], pt[1]+off[1], lbl,
      fontsize=14, fontweight='bold')
sq = patches.Rectangle((0,0),0.25,0.25,
    fill=False, edgecolor='black', lw=1.5)
ax.add_patch(sq)
ax.text(2,-0.35,'a = 4', ha='center', color='#1d4ed8')
ax.text(-0.5,1.5,'b = 3', ha='center', color='#059669')
ax.text(2.4,1.8,'c = 5', ha='center', color='#dc2626')
ax.set_aspect('equal'); ax.axis('off')
plt.savefig('output.png', dpi=130, bbox_inches='tight')

SketchMath architecture · Python-in-browser

Optional Interactive
Live API Output — sketchmath.com (captured April 2026)
import math

s_base = Slider(1, 8, increment=0.5, width=150)
s_base.value = 4.0
s_base.caption = "Base = %v"

s_height = Slider(1, 8, increment=0.5, width=150)
s_height.value = 3.0
s_height.caption = "Height = %v"

A = Point(0, 0); A.caption = "A"
B = Point(s_base.value, 0); B.caption = "B"
C = Point(0, s_height.value); C.caption = "C"

res = Polygon([A, B, C])
tri = res[0]; tri.color = "gold"; tri.opacity = 0.1

ang = Angle(B, A, C, minor=True)
ang.caption = "90°"

def update():
    B.x = s_base.value
    C.y = s_height.value
    a = s_base.value; b = s_height.value
    c = math.sqrt(a**2 + b**2)
    res[1].caption = f"a = {a:.1f}"
    res[3].caption = f"b = {b:.1f}"
    res[2].caption = f"c = {c:.2f}"

s_base.when_changed(update)
s_height.when_changed(update)
update()
ZoomIn(-2, -2, 10, 10)
This Python code runs via Skulpt in the browser, driving GeoGebra Classic 5 via a custom JS bridge.

The live SketchMath site uses Skulpt (MIT Python-in-JS runtime) with a custom $skulptGgbModule bridge to GeoGebra's JS API. AI generates Python code with sliders, callbacks, and dynamic updates. The architecture is sophisticated but adds significant complexity.

JSXGraph

MIT · Interactive SVG · No GeoGebra dependency

Candidate MIT License

JSXGraph is a standalone MIT-licensed geometry library that renders to SVG or canvas. No GeoGebra license concerns. Supports Euclidean geometry, curve/function plots, 3D surfaces, and animations. Smaller community than GeoGebra but much simpler API.
